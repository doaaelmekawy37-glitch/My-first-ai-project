# 🚀 مشروعي الأول في مجال الذكاء الاصطناعي

ده أول مستودع ليا وأنا بتعلم البرمجة والذكاء الاصطناعي بلغة بايثون.

## المشاريع اللي جواه:

### 1. hello_ai.py
أول برنامج ليا بيطبع رسالة ترحيب

### 2. ask_name.py  
برنامج بيسأل عن اسمك ويرحب بيك

### 3. guess_game.py
لعبة تخمين رقم من 1 لـ 10. الكمبيوتر بيختار رقم وانتي بتحاولي تجيبيه

## الهدف
بتعلم أساسيات بايثون خطوة بخطوة عشان أوصل للـ AI
### 4. calculator.py
آلة حاسبة بسيطة بتعمل جمع وطرح وضرب وقسمة
### 5. password_generator.py
مولد كلمة سر قوية عشوائية من حروف وأرقام ورموز
